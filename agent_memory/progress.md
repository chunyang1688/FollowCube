## 2026-11-12 · 练一练可以在魔方上自己转回去

- 打乱之后按住色块滑动，那一面会跟着转，转齐会提示还原成功。
- 点「还原」看步骤时也能自己转。转的和当前这一步一样，就记成完成；不一样就退出步骤，接着自己转。
- 浏览器里打乱、求出步骤后，往色块上滑了一下，因为和提示不同，页面退回自己转。

## 2026-11-11 · 修复小程序相对 H5 的运行阻塞

- 求解：Worker 消息同时接受 `res.message` 和直接载荷；初始化失败立刻拒绝排队请求；求解按钮不再被 `solverReady` 永久禁用。已还原状态直接提示，与 H5 一致。
- 3D 跟做：动画时钟改用 `Date.now()`。小程序 `canvas.requestAnimationFrame` 不传时间戳，旧写法会让「下一步」停在转动中。画布节点空时重试，不再第一次失败就拆掉 canvas。帧回调丢失时有超时兜底。
- 拍照：按 EXIF 方向把照片画进画布，预览用画布导出图，九宫格和取样像素对齐。手改格子的高亮不再滞后一拍。
